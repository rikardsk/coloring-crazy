# Proposed New Features & Enhancements

This document outlines potential future features and improvements for **ColoringCrazy**.

---

## 🎨 1. Vector Shape & Layer Enhancements
- **Visual Layer Manager**: A side panel listing all placed shapes (lines, circles, squares, spirals, speech bubbles) allowing users to select, reorder (drag-and-drop layer rank), toggle visibility (eye icon), or lock specific shapes.
- **Shape Opacity Slider**: Adjustable stroke & fill opacity for vector shapes to create semitransparent watermarks, glass-like overlays, or subtle guidelines.
- **Smart Snapping & Alignment Guides**: Toggleable magnetic snapping to grid lines, canvas center, or 45°/90° angle locks (holding `Shift`) when drawing or moving shapes.

---

## 🖌️ 2. Creative Brush & Painting Modes
- **Symmetry / Kaleidoscope Mode**: Radial mandala symmetry (2x, 4x, 8x symmetry axes). Painting on one side automatically mirrors the stroke across all axes.
- **Special FX Brushes**: Fun brush styles like **Glitter / Sparkles**, **Neon Glow**, **Soft Chalk / Crayon**, or **Rainbow Gradient** strokes.
- **Themed Color Palettes**: Pre-curated color palettes (e.g., *Pastel Sunset*, *Cyberpunk Neon*, *Forest & Earth*, *Ocean Waves*) with custom user palette saving.

---

## 🌟 3. Sticker & Stamp Library
- **Vector Stamps / Clipart**: A library of stampable vector icons (stars, hearts, flowers, crowns, clouds, sparkles) that behave like vector shapes so users can scale, rotate, color, and layer them behind or in front of paint.

---

## 📤 4. Export & Sharing Enhancements
- **Printable PDF Export**: High-resolution print export formatted for standard paper sizes (A4, US Letter) for physical coloring.
- **Before / After Slider & Animated Showcase**: An interactive split slider or short preview comparing the original blank line art to the completed colored artwork.
- **SVG Vector Export**: Export the artwork as a clean SVG file containing both vector shapes and vectorized color regions.

---

## ⌨️ 5. Workflow & Usability
- **Keyboard Shortcuts Cheat Sheet Modal**: Pressing `?` or clicking a `Help` icon opens a quick cheat sheet for shortcuts (e.g., `B` for Brush, `F` for Fill, `E` for Eraser, `V` for Select, `Delete` for removing selected shape, `Ctrl+Z` / `Ctrl+Y`).
